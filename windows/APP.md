# The program

This copy of the package leaves out `app/` to keep the repository small. The Windows program is
built on your PC from the **agentic-os** repository: clone https://github.com/LukeolafP/agentic-os,
open Claude Code in its `windows/` folder and follow `AGENTIC-OS-WINDOWS-BRIEF.md`. The zip on the
Releases page has `app/` inside it, ready to go.
